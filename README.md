# 🎤 Speech-Controlled Mouse Pointer

## 🚀 Project Overview

This project aims to develop a **speech-controlled mouse pointer system** using **C++**. Unlike typical implementations that rely on pre-built libraries, all functionalities here are implemented **from scratch**—including signal processing, feature extraction, and command recognition using a custom-trained **Hidden Markov Model (HMM)**.

### 🔍 Key Features

- 🎙️ **Custom Audio Dataset**: Over 1000 manually recorded audio samples for training and testing  
- 📈 **High Accuracy**: Achieves over 90% accuracy in real-time voice-controlled navigation  
- 💻 **Fully Native Implementation**: All core logic and models are written in C++, with no external ML libraries  
- 🖱️ **Supported Commands**:  
  - **Directional**: `up`, `down`, `left`, `right`  
  - **Actions**: `click`, `double click`, `right click`  

---

This project consists of two primary modules:

1. **`244101037_mouse_training_module`**  
2. **`244101037_testing_module`**

---

## 🧠 1. `244101037_mouse_training_module`

### 📄 Description

This module is responsible for generating an **HMM model** for each command using the training data. Each trained model is saved in a separate file corresponding to a specific command. It also produces a file named `Centroid_data.txt`, which stores the final centroids of the codebook used in vector quantization.

### 📂 Requirements

Ensure the following files are present in the project directory before running the module:

- `PI.txt`  
- `Transition_matrix.txt`  
- `State_matrix.txt`  

### 📤 Outputs

- HMM model files for each individual command  
- `Centroid_data.txt` containing the final centroids  

---

## 🎯 2. `244101037_testing_module`

### ⚠️ Pre-run Instructions

Before running this module, make sure to copy the following files (generated by the training module) into this project's folder:

- All command-specific HMM model files  
- `Centroid_data.txt`  

### 📄 Description

This module captures **live voice input** from the user and performs real-time speech recognition based on the trained models and centroid data. It interprets spoken commands and triggers corresponding mouse actions.
